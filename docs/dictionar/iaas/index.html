Ce este IaaS (infrastructura ca serviciu)?

Închiriezi de la un furnizor de cloud servere virtuale, discuri și rețea, plătite după consum; sistemul de operare, aplicațiile și datele le administrezi tu.

întrebări cu răspuns

IaaS (Infrastructure as a Service, în română infrastructură ca serviciu) este modelul de cloud în care închiriezi de la un furnizor servere virtuale, stocare și rețea, la cerere și plătite după consum, iar sistemul de operare, aplicațiile și datele le instalezi și le administrezi tu. Definiția de referință, NIST SP 800-145 (septembrie 2011), trasează granița: clientul nu administrează infrastructura cloud de dedesubt, dar controlează sistemele de operare, stocarea și aplicațiile instalate, plus, limitat, unele componente de rețea, cum ar fi firewall-ul gazdei. IaaS este stratul cu cel mai mult control și cu cea mai multă muncă; PaaS (platforma pregătită, la care aduci doar aplicația) și SaaS (aplicația gata făcută, la care aduci doar utilizatorii) stau deasupra lui.

O firmă mică alege IaaS când își mută serverele existente în cloud fără să rescrie aplicațiile (lift-and-shift), când are o aplicație veche sau doar pentru Windows pe care o platformă nu o rulează, sau când are nevoie de medii pornite doar la nevoie. Capcana: la IaaS, actualizările, backup-ul și securitatea rămân ale clientului. Un server mutat în cloud și lăsat fără actualizări e la fel de expus ca unul uitat în birou.

De ce contează pentru afacerea ta

✓Fără investiții în fiare

Serverele se închiriază după consum și se redimensionează din consola furnizorului — capacitatea urmează afacerea, nu ciclul de amortizare al unui server cumpărat.

✓Control total asupra mediului

Orice sistem de operare, orice configurație, orice aplicație moștenită — libertatea serverului propriu, fără camera serverelor.

✓Calea rapidă afară din sediu

Migrarea lift-and-shift mută sistemele existente în cloud fără rescrieri — riscul de incendiu, furt și pană de curent rămâne în urmă.

Cum funcționează IaaS

Într-o consolă a furnizorului sau prin API alegi regiunea și tipul de mașină virtuală (numărul de vCPU și memoria RAM), atașezi un disc (block storage), creezi rețeaua (rețea privată, adresă IP publică, reguli de firewall) și pornești mașina dintr-o imagine de sistem de operare. Plătești după timpul de rulare, stocarea folosită și traficul generat. Pentru că totul se creează prin API, infrastructura poate fi descrisă și ca cod (infrastructure as code), iar un mediu întreg se poate crea și șterge la cerere.

Definiția NIST SP 800-145 enumeră cinci caracteristici esențiale ale oricărui serviciu de cloud, deci și ale IaaS: autoservire la cerere, acces larg prin rețea, resurse puse în comun, elasticitate rapidă și serviciu măsurat. Practic, nu suni pe nimeni ca să primești un server, îl ceri singur, în câteva minute, și nu plătești mai mult decât ai folosit. Ce se întâmplă pe server după pornire, de la actualizările sistemului de operare până la aplicația instalată, rămâne treaba ta.

Cine administrează ce: on-premise, IaaS, PaaS, SaaS

Împărțirea răspunderii diferă de la un model la altul, iar paginile furnizorilor (Microsoft Azure și Amazon Web Services, „responsabilitate partajată”) o descriu la fel în esență. On-premise, totul e al tău, de la clădire la aplicație. La IaaS, furnizorul răspunde de centrul de date, serverele fizice, rețeaua fizică și virtualizarea; tu răspunzi de sistemul de operare, de aplicațiile instalate, de configurări, de date și de conturile cu acces.

La PaaS, furnizorul preia și sistemul de operare, iar tu păstrezi aplicația și datele. La SaaS, ți-a rămas ce nu poate prelua nimeni în locul tău: datele, utilizatorii cu drepturile lor și configurarea. Regula care se aplică în toate cele patru cazuri: datele și cine are acces la ele rămân ale clientului. De aceea mutarea în cloud nu mută și răspunderea pentru ele.

IaaS vs VPS

Un VPS (server virtual privat) se vinde de obicei ca un plan lunar fix: procesor, memorie, disc și trafic într-un singur pachet, administrat dintr-un panou. IaaS înseamnă componente comandate separat și la cerere — mașini virtuale, discuri separate, rețele private, copii instantanee (snapshot-uri), load balancere — create și șterse din consolă sau prin API și facturate după consum.

Un VPS luat de la un furnizor de cloud este cea mai simplă utilizare a IaaS, deci răspunsul scurt la „VPS-ul este IaaS?” este „în cele mai multe cazuri, da”. Diferența contează când vrei să scalezi, să automatizezi sau să plătești doar orele folosite. Pentru un site sau un magazin online, comparația pe simptome dintre hosting partajat, VPS și cloud are o pagină separată în secțiunea Comparații.

Exemple de IaaS și când îl alege o firmă

Exemple de servicii IaaS: Amazon EC2, Azure Virtual Machines, Google Compute Engine, Hetzner Cloud și OVHcloud Public Cloud. Toate pun la dispoziție mașini virtuale și discuri comandate la cerere, diferă prin regiuni, prețuri și servicii din jur.

O firmă alege de regulă IaaS pentru un ERP sau o aplicație veche mutate ca atare, pentru software de server care rulează doar pe Windows, pentru medii de test sau de pregătire oprite în afara programului de lucru sau pentru cerințe speciale de sistem de operare și de rețea. Despre dependența de furnizor: imaginile de mașini virtuale și sistemele standard Linux sau Windows se mută mai ușor între furnizori decât serviciile specifice unei platforme. Taxele de ieșire a datelor și Regulamentul european privind datele sunt tratate în comparația „Cloud românesc sau hyperscaler”.

Întrebări frecvente

Ce înseamnă IaaS?

IaaS vine de la Infrastructure as a Service, în română infrastructură ca serviciu. Un furnizor îți dă servere virtuale, discuri și rețea, la cerere și plătite după consum. Sistemul de operare, aplicațiile și datele le administrezi tu, ca pe un server propriu, dar fără hardware fizic de întreținut.

Care e diferența dintre IaaS, PaaS și SaaS?

Diferența este cât administrezi singur. SaaS e aplicația gata făcută, PaaS e platforma pe care rulează aplicația ta, IaaS sunt serverele goale. Multe firme le combină: email pe SaaS, aplicația proprie pe PaaS, ERP-ul vechi pe IaaS.

Este un VPS tot IaaS?

În cele mai multe cazuri, da: un VPS de la un furnizor de cloud este un server virtual închiriat, adică IaaS în forma lui simplă. Diferența este modul de vânzare. VPS-ul vine ca plan lunar fix, IaaS clasic se comandă pe componente și se facturează după consum.

Cine se ocupă de securitate la IaaS, eu sau furnizorul?

Amândoi, pe părți diferite. Furnizorul securizează centrul de date, hardware-ul, rețeaua fizică și virtualizarea. Sistemul de operare, firewall-ul, accesul, parolele, backup-ul și datele sunt ale clientului, conform paginilor de responsabilitate partajată ale Microsoft și Amazon Web Services.

Cât costă un server IaaS?

Un VPS pentru magazine online și trafic mediu costă orientativ 20–80 € pe lună; cloudul gestionat pentru aplicații serioase costă 50–300 € pe lună. La serverul propriu se adaugă curentul, răcirea, UPS-ul, înlocuirile și orele omului care îl administrează.

Pot muta un server existent pe IaaS fără să rescriu aplicația?

Da, prin lift-and-shift: copiezi mașina virtuală sau discul ori reinstalezi același sistem de operare și aceeași aplicație pe o mașină virtuală din cloud. Verifici apoi licențele pe hardware virtual, adresele IP, backup-ul și latența față de birou.
