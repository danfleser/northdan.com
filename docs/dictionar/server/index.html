Server: ce este și ce înseamnă

Serverul e calculatorul sau programul care primește cereri de la alte dispozitive, numite clienți, și le răspunde: site-uri, email, fișiere, aplicații.

Un server este un calculator sau un program care primește cereri de la alte dispozitive din rețea și le trimite ce au cerut: pagina site-ului, emailul, fișierul. Dispozitivele care cer (laptopul, telefonul, browserul) se numesc clienți. Cuvântul vine din engleză (server, de la to serve, „a servi”) și numește un rol, nu o cutie anume. Diferența față de un calculator obișnuit vine din exigențele rolului: pornit permanent (căderea lui e căderea serviciului pentru toți), dimensionat pentru mulți simultan, construit redundant la componentele care mor primele și administrat ca atare — actualizat, monitorizat, cu backup. Formele fizice s-au diversificat până la a face cuvântul abstract: serverul din rack-ul firmei, serverul virtual (o felie dintr-un fizic — VPS-ul), serverul din cloud (undeva într-un data center, închiriat la oră) și chiar „serverless” (unde infrastructura există dar n-o mai vezi deloc) — în toate cazurile însă, undeva, un calculator real servește cererile tale.

Pentru un administrator de firmă, subiectul se reduce la câteva decizii și igiene concrete: unde trăiesc serverele de care depinzi (inventarul scurt: site-ul, emailul, ERP-ul, fișierele — pe ce servere stau, ale cui sunt, cine le administrează; surprinzător de multe firme nu pot răspunde), decizia de amplasare pentru fiecare (la sediu — doar cu motiv real: echipamente locale, cerințe stricte; în rest cloud sau data center, unde curentul, răcirea și paza nu sunt problema ta), și igiena nenegociabilă a oricărui server, oriunde ar fi: actualizări ritmice (serverul neactualizat expus la internet e statistic deja scanat de atacatori), acces securizat (chei și 2FA, nu parole simple pe RDP deschis — poarta clasică a ransomware-ului), monitorizare (să afli de la sistem, nu de la clienți) și backup testat în altă locație. Iar întrebarea care rezumă maturitatea operațională: „dacă serverul X moare acum, cine intervine, în cât timp, și de unde restaurăm?” — pentru fiecare server din inventar, răspunsul trebuie să existe înainte de incident.

De la al doilea punct de lucru la magazinul online, extinderile firmei stau pe servere bine alese — decizia de infrastructură luată corect se amortizează la fiecare pas următor.

Cum funcționează un server: modelul client-server

Funcționarea se descrie în trei pași. Mai întâi, sistemul DNS transformă numele site-ului în adresa IP a serverului. Apoi clientul trimite cererea: de exemplu, browserul cere o pagină. Serverul primește cererea pe un port, o procesează (citește din baza de date, rulează codul aplicației) și trimite răspunsul, de regulă în fracțiuni de secundă.

Cuvântul „server” are două sensuri. Primul este mașina (hardware-ul), calculatorul pornit în rack sau în data center. Al doilea este programul care răspunde cererilor, de exemplu un server web precum Nginx sau Apache. O singură mașină fizică poate rula mai multe programe-server în același timp: web, email și bază de date pe aceeași mașină nu e neobișnuit.

Tipuri de servere

După funcție: server web (livrează site-uri), server de aplicații (rulează logica programelor), server de baze de date, server de email (SMTP pentru trimitere, IMAP pentru citire), server de fișiere (inclusiv NAS-ul de birou), server DNS (traduce nume în adrese IP), server proxy (intermediar între clienți și internet) și server de jocuri.

După forma în care există: serverul fizic stă într-un rack sau într-o carcasă tower, la sediu sau într-un data center. Serverul dedicat este o mașină fizică închiriată, folosită de un singur client. Serverul virtual (VPS) este o felie dintr-o mașină fizică, izolată de celelalte felii. Serverul din cloud se închiriază la oră, iar „serverless” înseamnă că rulezi cod fără să administrezi tu serverul. Fiecare dintre aceste forme are propriul articol în dicționar.

Potrivit W3Techs (18 noiembrie 2026), dintre site-urile al căror server web îl cunoaște W3Techs, Cloudflare Server are 34,6%, Nginx 29,7%, Apache 20,5% și LiteSpeed 13,2%. Dintre cele al căror sistem de operare îl cunoaște, 92,2% rulează pe sisteme de tip Unix (Linux inclus), iar 7,9% pe Windows. Un site poate folosi mai mult de unul.

Server sau calculator obișnuit: diferențele

Orice calculator obișnuit poate face pe server: instalezi un program-server și el începe să răspundă cererilor. Diferența ține de fiabilitate, nu de rol. Un server dedicat serviciului are, de regulă: funcționare 24/7; dimensionare pentru mulți utilizatori simultan; surse de alimentare duble; discuri în oglindă (RAID); memorie cu corecția erorilor (ECC); administrare de la distanță, fără monitor și tastatură lângă el.

Sistemul de operare diferă și el: distribuții Linux sau Windows Server, nu o ediție pentru birou. Iar administrarea este altfel: actualizări ritmice, monitorizare cu alerte și backup testat, pentru că atunci când serverul cade, cad toate serviciile care depind de el.

Cum se scrie: serverul, nu server-ul

Forma corectă este serverul, scrisă legat, fără cratimă. Dicționarul ortografic al Academiei (DOOM 3, 2021) înregistrează „server” ca substantiv neutru, cu pronunția [servăr] și pluralul servere. Formele articulate sunt serverul, serverului (genitiv-dativ), serverele și serverelor.

Definiția din DEX '09 este: „Computer sau program care conectează utilizatorii din rețea la o sursă centralizată sau la o bancă de date. Din engl. server.” Sursa pentru ambele: dexonline.ro/definitie/server.

Întrebări frecvente

Mai are sens un server fizic la sediu în era cloud?

Doar cu motiv concret: echipamente locale care cer răspuns instant (producție, case de marcat, camere), cerințe stricte de localizare a datelor, sau volume mari constante unde calculul total iese în favoarea fierului propriu. Pentru restul — site, email, aplicații, fișiere — cloudul sau serverul închiriat în data center câștigă la fiabilitate, securitate fizică și lipsa grijilor. Iar dacă serverul de la sediu rămâne: UPS, backup extern și un responsabil clar sunt minimul absolut.

Ce înseamnă că serverul „a picat” și cum se previne?

Orice îl scoate din serviciu: defecțiune hardware, pană de curent, sistem blocat, atac, disc plin. Prevenția matură e stratificată: redundanță la componentele critice, monitorizare cu alerte (problema anunțată înainte să devină cădere — discul care se umple se vede cu zile înainte), actualizări ritmice, și — pentru că prevenția perfectă nu există — plan de restaurare exersat: backup testat + pași documentați + un timp-țintă de revenire asumat.

Serverul nostru e administrat de „băiatul cu IT-ul” — e suficient?

Întrebările-test spun răspunsul: există backup testat prin restaurare? actualizările se fac ritmic, documentat? accesul e securizat (2FA, fără porturi de administrare deschise în internet)? există monitorizare? cine intervine când omul e în concediu? Dacă răspunsurile șchioapătă, nu omul e problema, ci modelul: un singur om, fără proceduri, e un punct unic de avarie. Soluțiile: proceduri scrise + al doilea om instruit, sau contract de administrare cu un furnizor cu SLA.

Cum se scrie corect: serverul sau server-ul?

Serverul, fără cratimă. DOOM 3 (2021) înregistrează „server” ca substantiv neutru, cu pluralul servere. Formele articulate sunt serverul, serverului, serverele și serverelor, toate scrise legat. Forma „server-ul” nu apare în dicționarul ortografic al Academiei.

Care este diferența dintre un server și un calculator obișnuit?

Diferența ține de fiabilitate, nu de rol: orice calculator poate răspunde cererilor altor dispozitive, dar serverul funcționează non-stop, deservește mulți utilizatori simultan și are, de regulă, componente redundante (surse duble, discuri în RAID) și administrare de la distanță. Un calculator obișnuit poate face pe server, dar fără aceste garanții.

Ce tipuri de servere există?

După funcție: web, de aplicații, de baze de date, de email, de fișiere, DNS, proxy și de jocuri. După formă: fizic la sediu sau în data center, dedicat (închiriat unui singur client), virtual VPS, în cloud și serverless. Același server fizic poate rula mai multe funcții simultan.
