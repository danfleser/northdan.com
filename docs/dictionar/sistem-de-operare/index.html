Ce este un sistem de operare?

Programul de bază al oricărui calculator, telefon sau server: împarte hardware-ul între aplicații și le oferă serviciile comune.

7

6
întrebări cu răspuns

Sistemul de operare (SO; în engleză operating system, OS) este programul de bază al unui calculator, telefon sau server: administrează procesorul, memoria, stocarea și perifericele și le pune la dispoziția aplicațiilor și a utilizatorului. Firmware-ul (BIOS sau UEFI) doar pornește echipamentul și încarcă sistemul de operare; aplicațiile, de la browser la programul de facturare, rulează deasupra lui. Exemple: Windows, macOS, Linux și ChromeOS pe calculatoare, Android și iOS pe telefoane, Linux și Windows Server pe servere. În România, în octombrie 2026, Windows apărea pe 91,35 % din vizitele de pe calculatoare, iar Android pe 73,8 % din cele de pe telefoane (StatCounter).

Pentru o firmă, sistemul de operare decide ce programe rulează, cât costă licențele și până când primește actualizări de securitate. Windows 10 a ieșit din suport pe 14.10.2025 și mai primește doar actualizări ESU (consumatori până la 12.10.2027; firme contra cost, cel mult trei ani), iar în octombrie 2026 încă 23,09 % din vizitele de pe Windows din România veneau de pe Windows 10. Întrebarea de pornit: ce sisteme de operare rulează în firmă, pe ce versiuni, și care dintre ele mai primesc actualizări de securitate?

Rolul sistemului de operare

Fără sistem de operare, fiecare aplicație ar trebui să controleze singură hardware-ul, iar două programe nu ar putea rula în același timp. Sistemul de operare face șase lucruri: planifică procesele pe procesor, împarte memoria între ele, organizează fișierele și drepturile de acces la ele, vorbește cu perifericele prin drivere, gestionează conturile de utilizator și permisiunile și oferă interfața, grafică sau în linie de comandă.

Nucleul (kernel) este partea care are acces direct la hardware; restul sistemului (interfața, serviciile, uneltele) se sprijină pe el. Securitatea unui calculator pornește de aici: sistemul de operare decide cine are voie să citească ce și ce program poate modifica sistemul.

Tipuri de sisteme de operare

După dispozitiv: pentru desktop și laptop (Windows, macOS, Linux, ChromeOS), pentru telefoane și tablete (Android, iOS), pentru servere (Linux, Windows Server) și încorporate, adică ascunse în echipamente precum casele de marcat, terminalele POS, routerele sau utilajele. Unele echipamente industriale folosesc sisteme în timp real, care garantează că o operație se termină într-un timp fix.

După licență: proprietare (Windows, macOS, iOS) și open source (Linux, baza Android); o licență de software stabilește cine are voie să folosească, să copieze și să modifice programul. După utilizare: sisteme pentru un singur utilizator, cum sunt telefoanele, și multi-utilizator, unde mai multe conturi lucrează simultan pe aceeași mașină, cum sunt serverele.

Exemple și cote de piață (octombrie 2026)

Pe calculatoare, în lume, Windows are 76,62 %, macOS 15,71 %, Linux 5,66 % și ChromeOS 2,02 %. În România, Windows are 91,35 %, macOS 5,15 % și Linux 3,41 %. Pe telefoane, în lume, Android are 72,39 % și iOS 27,58 %; în România, Android 73,8 % și iOS 26,17 %.

Între versiunile de Windows de pe calculatoare, în România Windows 11 are 76,7 % și Windows 10 are 23,09 % (în lume: 74,2 % și 25,22 %). Cifrele sunt StatCounter, octombrie 2026. StatCounter măsoară vizitele de pagină pe site-urile care îi poartă scriptul de urmărire, nu dispozitivele instalate, deci arată folosirea, nu numărul de calculatoare.

Sisteme de operare pentru servere

Serverul este mașina (sau mașina virtuală, ca într-un VPS), iar sistemul de operare este stratul de pe ea. Pe servere se folosesc distribuții Linux (Debian, Ubuntu Server, Red Hat Enterprise Linux și variantele compatibile AlmaLinux și Rocky Linux) și Windows Server. Linux rulează pe 64,5 % dintre site-urile al căror sistem de operare este cunoscut (W3Techs, 18.11.2026).

Windows Server este alegerea legitimă acolo unde ecosistemul o cere: Active Directory, aplicații .NET clasice, softuri de business care merg doar pe Windows. Atenție la ciclul de viață: suportul extins pentru Windows Server 2016 se încheie pe 12.01.2027, după care actualizările de securitate sunt disponibile doar prin ESU plătit, până în 2030.

Ce decide o firmă: suport, licențe, standardizare

Ciclul de viață: fiecare sistem are o dată de sfârșit de suport, după care vulnerabilitățile noi rămân deschise. Stațiile pe versiuni ieșite din suport, de regulă lângă casele de marcat sau utilajele, sunt printre cele mai exploatate uși din firmele mici, iar inventarul versiunilor, cu calendarul înlocuirilor, este igienă de bază. Windows 11 cere procesor compatibil și TPM 2.0, așa că unele calculatoare vechi nu pot trece la el.

Licențierea: Windows se plătește, iar pirateria pe stațiile firmei este risc juridic și de securitate deopotrivă. Majoritatea distribuțiilor Linux pentru servere sunt gratuite; Red Hat Enterprise Linux și SUSE se plătesc ca abonament de suport.

Standardizarea: un parc cu aceleași versiuni și configurări se administrează mult mai ieftin decât unul în care fiecare dispozitiv e diferit. La telefoanele de serviciu, administrarea prin MDM ține datele firmei separabile și ștergibile de la distanță.

Compatibilitatea: softul de business românesc clasic este frecvent doar pentru Windows, detaliu care decide singur ce rulează la contabilitate.

Întrebări frecvente

Ce risc real e să mai rulăm Windows-uri vechi, ieșite din suport?

Vulnerabilitățile descoperite după data de sfârșit nu se mai repară; Windows 10 a ajuns aici pe 14.10.2025, iar fără ESU nu mai primește remedieri. Mașina devine exploatabilă cu unelte automate și e punctul de intrare spre restul rețelei. Identifică-le (des sunt lângă case de marcat și utilaje), izolează-le dacă înlocuirea întârzie și planifică înlocuirea.

Windows Home sau Pro pe calculatoarele firmei?

Pro, aproape întotdeauna. Home are Device Encryption pe hardware compatibil, dar fără administrare centrală. Pro adaugă BitLocker complet, cu cheile de recuperare păstrate de firmă, plus alăturarea la domeniu sau la Microsoft Entra ID (fostul Azure AD) și politici centralizate. Diferența de preț e mică, mai ales la calculatorul cumpărat cu licența preinstalată.

Contează pe ce sistem de operare rulează serverele aplicațiilor noastre?

Pentru buget și operare, da. Majoritatea distribuțiilor Linux pentru servere sunt gratuite, deci dacă plătești licențe Windows Server pentru un site obișnuit, întreabă de ce. Windows Server rămâne legitim pentru aplicații .NET clasice, Active Directory și softuri doar pentru Windows. Decide arhitectul, dar costul licențierii este o întrebare cu răspuns verificabil.

Ce sisteme de operare sunt disponibile pentru servere?

Cele mai folosite sunt două familii: distribuții Linux (Debian, Ubuntu Server, Red Hat Enterprise Linux și variantele compatibile AlmaLinux și Rocky Linux) și Windows Server. Linux rulează pe 64,5 % dintre site-urile al căror sistem de operare este cunoscut (W3Techs, 18.11.2026). Alegerea depinde de aplicațiile care trebuie să ruleze, nu de preferințe.

De ce este important sistemul de operare?

Fără el nu rulează nicio aplicație, pentru că el dă acces la procesor, memorie, disc și rețea. În plus, hotărăște ce programe pot rula, cât costă licențele și cât timp primești actualizări de securitate. Un sistem ieșit din suport rămâne deschis atacurilor chiar dacă aplicațiile de pe el merg bine.

Mai putem folosi Windows 10 în firmă?

Merge, dar fără actualizări de securitate gratuite din 14.10.2025. Pentru organizații, actualizările ESU sunt plătite, per dispozitiv, pe ani, cel mult trei ani. Trecerea la Windows 11 cere TPM 2.0 și procesor compatibil, deci verifică fiecare calculator înainte să cumperi ESU sau echipamente noi.
