O firmă românească de dezvoltare software

Northdan Soft construiește software la comandă pentru firme și instituții publice: aplicații web și mobile, sisteme interne, digitalizare și integrare AI. Firma există din 2021.

Pe lângă proiectele pentru clienți, construim și operăm propriile produse: SocialKit, eFacturaSPV și Resort Buggy. Ele arată că putem duce un produs de la idee la software live, folosit în producție.
