What Is a Backend? — IT Glossary

The unseen part of an application: the server, the database and the business rules doing the heavy work behind the interface.

What Is a Database? — IT Glossary

What Is Big Data? — IT Glossary

What Is Business Intelligence? — IT Glossary

The discipline of turning company data — sales, stock, costs — into live reports and dashboards that decisions can stand on.

What Is a Cache? — IT Glossary

Temporary memory that keeps copies of frequently requested data — so websites and applications don’t redo the same work on every visit.

What Is a CDN? — IT Glossary

Content Delivery Network: a globally distributed set of servers that serves copies of your website from the city closest to each visitor.

What Is a Chatbot? — IT Glossary

A program that converses with your customers — on your website, WhatsApp or Messenger — replying instantly, at any hour.

What Is CI/CD? — IT Glossary

Software's assembly line: every change is tested and published automatically — small, frequent releases with no sleepless launch nights.

What Is Cloud Computing? — IT Glossary

Computing power, storage and applications rented over the internet and paid by consumption — the electricity grid of modern IT.

What Is a CMS? — IT Glossary

Content Management System: the admin panel where your own team edits the site's texts, images and pages — no developer on the phone.

What Is Code Review? — IT Glossary

The four-eyes rule applied to programming: code written by one developer is read and approved by another before it enters the product.

What Is Computer Vision? — IT Glossary

The branch of AI that teaches computers to see: recognizing objects, text, faces and defects in images and video.

What Is Containerization? — IT Glossary

Packaging an application with everything it needs so it runs identically on any server — the shipping container of software.

What Is a Web Crawler? — IT Glossary

The robot that roams the web from link to link and reads pages — Google’s eyes on your website.

What Is a CRM? — IT Glossary

Customer Relationship Management: the system where all client data and conversations live — your company's sales memory.

What Is a Dashboard? — IT Glossary

What Is a Data Warehouse? — IT Glossary

The company's central data store: information from every system, gathered, cleaned and organised specifically for analysis.

What Is Debugging? — IT Glossary

The investigation that finds and eliminates the cause of a software error — the detective part of programming.

What Is Deep Learning? — IT Glossary

The AI branch built on neural networks with many layers — the technology behind ChatGPT, image recognition and instant translation.

What Is Deployment? — IT Glossary

Going live: the moment a new software version reaches the real servers and the real users.

What Is DevOps? — IT Glossary

What Is OCR? — IT Glossary

Optical Character Recognition: turning images of text — scans, photos, PDFs — into text and data software can process.

What Is Omnichannel? — IT Glossary

Every channel a company has — physical store, online, phone, WhatsApp, social — connected into one continuous customer experience.

What Is On-Premise? — IT Glossary

Infrastructure "at home": servers and software running on the company's premises and equipment — total control, total responsibility.

What Is Open Source? — IT Glossary

Software whose source code is public: anyone may study, use, modify and share it — the invisible foundation of the modern internet.
